# CpE Pathfinder

Android-first curriculum planning prototype for FEU Institute of Technology students. This version ships with a maintained BSCpE curriculum and turns the official sequence into a clustered prerequisite map with a personal, persistent Raid Planner.

## What is implemented

- Built-in program catalog with BSCpE as the first selectable program; no student-facing HTML upload is required
- Maintained BSCpE curriculum with course code, title, units, prerequisites, and combined lecture/lab links
- Guided Academic Setup: choose a program, enter the first college academic year, record history one year at a time, then choose only currently eligible active courses
- Atomic year/term completion actions plus individual subject controls, all backed by the same strict prerequisite validator used in Progress
- One horizontally explorable **Curriculum Map** generated by a weighted hierarchical graph layout rather than year/term columns or fixed course coordinates
- A distinct far-left first-term starting region, left-to-right prerequisite ranks, and soft academic-field regions positioned from graph affinity
- Graph analysis for direct unlocks, total downstream reach, prerequisite/downstream depth, cross-field bridge role, curriculum-data cycles, and distance/ancestry to Thesis and Internship
- A dynamically composed central degree backbone: Mathematics & Physics anchors the spine through field metadata, while supporting/general-engineering/CpE-core priorities and graph affinity keep Programming, Electronics, Embedded, Networks, and Capstone close to that core and move minor branches outward
- Near-full-screen collapsible **Raid Planner** with a compact raid timeline, compact roster, and responsive 1–4-column Available Choices workspace; raids represent chronological trimesters, can be renamed, and show course count, units, GWA, and load warnings
- Raid 1 always preserves the official first-term roster; later raids start from the student's setup progress and can be customized
- Strict available-course lighting: unlocked courses glow on the map and appear as Raid Planner choices, while locked courses remain visible and cannot be dragged
- Invalid additions snap back with an explanation; prerequisite, corequisite, and lecture/lab rules remain deterministic
- Four layout-aware map-tile tiers plus distinct angular **Thesis Boss** and terminal-shaped **Internship Destination** milestone designs at roughly twice their previous visual mass; their actual dimensions participate in collision handling
- A tile-origin, status-independent Thesis glow with no detached dashed-box aura
- Explicit Foundational Gateway semantics for Calculus 1, Physics 1, and Engineering Data Analysis; their influence propagates through descendant placement and connector prominence
- Deterministic field titles anchored to real cluster bounds with collision checks against nodes, other titles, and major connectors
- Distinct **Conquered**, **Active Raid**, **Available**, **Planned**, **Retake**, and **Locked** visual states across every theme
- Clicking a map course selects and highlights its path without moving the camera; choosing **Locate** from Raid Planner enters a compact locator mode, centers the exact tile at any starting zoom, and restores the previous zoom/pan when returning
- Available Raid choices show compact previews derived from real difficulty/workload/usefulness ratings, or an explicit **No ratings yet** state
- Routed, rounded, horizontal-first prerequisite branches with shared trunks, virtual routing points, crossing reduction, and data-driven minor/normal/core/thesis prominence; distant Thesis ancestry becomes the main trunk and the final approach receives the strongest energy
- Hover/click ancestor-and-descendant highlighting with continuously mounted animated paths, direct-relation labels, and de-emphasis of unrelated branches
- Source-department-colored arrows whose contrast and intensity follow the active palette
- Captured drag navigation from empty desktop map space, touch panning, wheel roaming, Shift+wheel horizontal movement, Ctrl/Command+wheel or touchpad pinch zoom, and complete-map fit controls
- Full Screen map mode with a visible exit control and preserved zoom, pan, course selection, and pathway highlighting
- Separate retake attempts that preserve every original term, status, and grade
- Known FEU CpE corequisite handling for COE0001 + COE0003, including joint copying, movement, validation, and chain grouping
- Combined lecture/laboratory tiles with visible lab details and shared planning/status behavior
- Advisory warnings below 12 units, above 22 units, and for delayed prerequisite chains
- Shared Passed, Active, Planned, Available, and Locked visual semantics across Setup, Progress, the map, and Raid Planner; retakes remain explicit attempts
- Strict ACTIVE/PASSED rejection with an on-screen error naming every missing prerequisite; PLANNED keeps Raid planning behavior
- Calculated Current Raid based on the first enrollment year, current date, and FEU trimester sequence
- Raid strategy modes for Thesis Priority, Internship Priority, and Lighter Workload, with map-linked highlights and strictly eligible graph-derived recommendations
- Optional grade entry from Progress and course details, with per-attempt grades and unit-weighted GWA for every raid
- Responsive right-side course details on desktop and bottom sheet on Android
- All/GED/COE/CPE filtered Progress and Ratings views, side-by-side desktop rating comments/form, Android rating bottom sheet, and one editable 300-character review per account/course
- Report, delete, and administrator-moderation controls
- FEU Green, Dark, Black–Maroon, Black–Orange, Pastel Pink, and device-following color palettes
- Cloud-ready anonymous username/password accounts and private plan sync through Supabase
- Local fallback mode while Supabase is not connected

Course offerings are deliberately not checked. This app is an unofficial planning aid and never performs registration.

## Run on Android

This project uses Expo SDK 54 so it can be previewed in the compatible Expo Go Android app during the current SDK transition.

```powershell
npm install
npm run android
```

If no Android emulator is installed, run `npm start`, scan the QR code with Expo Go, and keep the phone and development machine on the same network.

## Run as a website

The same project also targets modern desktop and mobile browsers.

```powershell
npm install
npm run web
```

Choose BSCpE during Academic Setup. The curriculum is bundled with the app, so no local curriculum file is requested.

## Accounts and Supabase

Follow [SUPABASE_SETUP.md](SUPABASE_SETUP.md) to enable shared anonymous-username accounts, private cloud plans, ratings, reporting, and the `Kynsomnic` administrator role. Username-only accounts intentionally have no email recovery. Without environment values the app remains usable in local preview mode.

## Version 1 assumptions

- SOLAR's **LABORATORY** column links a lecture to a lab course and is treated as a same-trimester corequisite.
- The export does not contain course descriptions or a separate corequisite column. Missing descriptions are stated as unavailable; inferred lecture/lab corequisites are symmetric.
- Underload and overload are allowed because planning hypotheticals is a stated requirement. The app warns outside 12–22 units instead of blocking.
- Passed courses remain visible as conquered map nodes. Active courses stay assigned to the calculated current raid, while future raid courses remain Planned.
- Invalid drops snap back and explain the exact prerequisite/corequisite rule that rejected the move.
- Future pending courses are added from unlocked map nodes rather than prefilled into future raids.
- A course can be duplicated only through the explicit retake-attempt action.
- Grades accept a consistent numeric scale from 0–100, remain optional, and never change progress status automatically.
- Community difficulty adds a stronger outline after at least five ratings but never changes structural tile size; prerequisite influence and milestone metadata determine size.
